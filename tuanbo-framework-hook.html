一句话结论：铁粉经济撑起 95% 音浪，路人付费全月仅 4.82%（客单价塌陷，并非 0）—— 拉新漏斗在「关注」和「路人付费客单价」两层断裂，留存被 7 个老粉天花板锁死。头号命题 = 提升路人付费客单价。

一、问题定位（拉新 + 留存需求）

需求双目标
  • 拉新曝光→进房→关注→付费的全漏斗，目前逐层断裂，尤其「进了不关注」「路人付费客单价塌陷（占比4.82%）」。
  • 留存已有付费用户靠 7 个老粉撑着，但新客留不住、老客天花板肉眼可见 —— 不是「老粉在流失」，是「新粉根本没进来」。
最痛层（全漏斗定位）：不在「进了不留」，在 「进了不关注 + 关注不付费 + 路人付费客单价塌陷（占比4.82%）」。铁粉经济天花板 = 那 7 个人，再高也有限，增长必须提升路人付费客单价。

四、拉新留存运营命题（基于框架的落地方向）

  1. 止损别再堆热点流量：赵露思352万曝光换5.5万音浪（路人仅6.12%），ROI极低。重心转常态场质量 + 提升路人客单价。
  2. 头号提升「路人付费客单价」：把随手小心心运营成有效小额（灯牌小费/专属打赏），Hook 模型落地；验证看路人付费占比 4.82%→提升 + 场均客单价。
  3. 分层主播分层用：糖炒栗子带教沉淀、小丑做星守护深度样板、小龙虾提新客价值。
  4. 体系星守护成长体系：把小丑12800经验复制，让更多老粉往星守护走，扩留存基底（粉丝团等级运营照抄）。

五、Hook 模型 · 路人0→1付费钩子脚本

设计总览（四步循环）

① 触发 Trigger
进房1分钟内点名 / 开播前热点预告 → ② 行动 Action
极低门槛：亮灯牌(0.1元)/小心心，不催大额 → ③ 多变奖励 Reward
被点名 / 专属称呼 / 下次被记住 → ④ 投入 Investment
星守护 / 亲密值 → 加载下次回访

核心原则：从0到1入口≈0摩擦；「被认真对待」靠个性化变量槽（昵称/共同记忆）防工业糖；边界红线不破。

脚本 A · 进房1分钟内「被看见」触发（主持/主播通用）

时机：新用户进房 0–60 秒，公屏出现新 ID 或灯牌提示。
主持：「刚进来的【昵称】扣1让我看到你～欢迎第一次来咱们家！」
主播接：「【昵称】对吧？记住了，待会这首专门给你留个镜头。」→ 被看见→被记住
主持回收：「亮个灯牌就是咱家门禁卡，【昵称】以后你来我第一个喊你。」→ 身份锚点
变量槽【昵称】实时读取，禁止群发模板（无昵称=工业糖）。

脚本 B · 才艺高潮后「多变奖励」行动（主播主导）

时机：才艺名场面/高光段落结束瞬间。
主播：「刚才这段值不值一个小心心？新来的家人亮灯牌就行，不催别的。」
主持：「亮灯牌自动解锁【团宠】称呼，下次你来【主播名】第一个喊你。」→ 专属感+不确定回报
主播点名已亮牌新粉：「【昵称】灯牌我看到了，记下了哈。」→ 定制糖
只引导灯牌/小心心（≤1元），不在此刻推大额礼物。

脚本 C · 下播前「投入」加载（小丑星守护样板）

时机：下播前 5 分钟，针对已亮灯牌但未升守护的新粉。
主持：「今天新亮灯牌的宝子，点一下【粉丝团】就能解锁星守护，下次开播专属提醒直接弹给你。」
主播：「【昵称】今天来了我记着了，升个守护咱就是自己人了，下周专属曲我cue你。」→ 沉没成本+回访理由
主持收尾：「守护不是花钱，是咱家门禁卡plus，下次你来不用重新介绍自己。」
样板小丑星守护贡献值全队最高(12800)，让他主跑此脚本，经验复制给其他主播。

边界红线（写进执行规范）

1. 不催大额：钩子阶段只到灯牌/小心心，大额等准社会关系建立后自然发生。
2. 不承诺排他：禁「只对你/唯一」类话术（对应维护判断指标·边界合规，防工业糖/越界）。
3. 变量槽必填：无【昵称】/无共同记忆点的话术不发，宁可少发。
4. 人闸：脚本为素材库，主播/主持真人表达，不自动群发。
